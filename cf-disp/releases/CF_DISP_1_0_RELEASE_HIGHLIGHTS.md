# CF-DISP-1.0 Release Highlights

## Displacement Context Contract + Carrier Registry
Introduces one reusable displacement context and carrier registry without forking PVX or any scoring/recommendation engine.

Primary implementation:
- `contracts/CF_DISP_CONTEXT_CONTRACT.json`
- `assets/js/displacement-carriers.js`
- `assets/js/displacement-context.js`
- `server/pvx-displacement-core.mjs`

Acceptance result: complete in the integrated `CF-DISP-5.2` production candidate.

# CF-DISP Google Search launch checklist

- [ ] `/nonrenewal/` and `/nonrenewal/safeco/` are live over HTTPS.
- [ ] Mobile and desktop displacement intake smoke tests pass.
- [ ] Google Ads auto-tagging is enabled.
- [ ] Data Manager / enhanced-conversions-for-leads destination is configured using the current account-side workflow.
- [ ] Lead, Qualified Lead, Quote Started, Quote Delivered and Policy Bound conversion actions exist.
- [ ] Controlled test confirms click identifier retention and downstream conversion acceptance.
- [ ] California location setting uses presence, not mere interest, unless a deliberate exception is approved.
- [ ] Search Network only; Display expansion and Search Partners off for the initial test.
- [ ] Exact + phrase keywords imported from `KEYWORDS.csv`.
- [ ] Negative keywords imported before launch.
- [ ] RSA assets reviewed for current Google policy and agency compliance.
- [ ] Safeco/Liberty trademarks are not used to imply affiliation in ad creative.
- [ ] Initial daily budgets and CPC guardrails are approved.
- [ ] Search terms reviewed daily during the initial learning period.
- [ ] Decisions use qualified conversations/quotes/binds, not CTR or raw leads alone.
